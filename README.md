# Prórroga ⏱️

Página con los chistes internos del equipo. Al abrirla suena "prórroga".

- **Agregar chistes:** edita `chistes.js`.
- **Botonera de Nicolás:** sube el audio a `audio/` y agrégalo en `botonera.js`.
- **Consejos del tío Nicolás:** edita `consejos.js`.
- **Viste a la Koyonka:** sube la cara de Sebastián como `img/sebastian.png`.
- **Impostores de José:** agrega fotos en `FOTOS_IMPOSTORES` dentro de `impostor.html`.
- **Clave de acceso:** está en `clave.js` (guardada como hash SHA-256).
- **Audios:** `audio/parte2.mp3` suena al abrir (cortado de `audio/original.ogg`).

Se publica con GitHub Pages desde la rama `main`.
